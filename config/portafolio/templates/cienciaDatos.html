Caso destacado · Minería 4.0

Predicción de combustible en camiones CAEX

Problema: en minería, un camión que se queda sin combustible a mitad de ciclo detiene la producción. Objetivo: anticipar el nivel de combustible de cada camión y decidir cuál debe recargar primero. Proyecto desarrollado con datos de sensores en el bootcamp de Minería 4.0 (BHP · UNAB · SENCE).

1,84 L
MAE en test
2,56 L
RMSE en test
≈ 1,00
R² (nivel en miles de litros)
30·60·90
min de horizonte simulado

Cómo lo resolví

  1. Integración: JOIN de sensores de combustible con la metadata de equipos.
  2. Feature engineering temporal: nivel_lag_1 (lectura previa) y dt_min (minutos entre lecturas).
  3. Validación honesta: split temporal 80/20 sin shuffle, para no filtrar el futuro al entrenamiento.
  4. Modelos: Regresión lineal como base, comparada con Lasso y Random Forest.
  5. Decisión: simulación a 30/60/90 min y semáforo de criticidad para ordenar las recargas.

El R² cercano a 1 refleja la naturaleza casi determinista del consumo en el corto plazo; lo revisé explícitamente para descartar filtración de información. El error medio de unos pocos litros es pequeño frente a la variabilidad total del estanque.

Esquema simplificado del enfoque

# Features temporales por equipo
df = df.sort_values(["equipo_id", "timestamp"])
df["nivel_lag_1"] = df.groupby("equipo_id")["nivel"].shift(1)
df["dt_min"] = df.groupby("equipo_id")["timestamp"] \
    .diff().dt.total_seconds() / 60

# Split temporal (sin shuffle)
cut = int(len(df) * 0.8)
train, test = df.iloc[:cut], df.iloc[cut:]

model = LinearRegression().fit(train[FEATS], train["nivel"])
pred = model.predict(test[FEATS])
print(mean_absolute_error(test["nivel"], pred))

    return "VERDE"
