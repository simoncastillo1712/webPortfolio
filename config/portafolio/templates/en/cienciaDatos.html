Featured case · Mining 4.0

Fuel prediction for CAEX haul trucks

Problem: in mining, a truck that runs out of fuel mid-cycle halts production. Goal: anticipate each truck's fuel level and decide which one should refuel first. Project built with sensor data during the Mining 4.0 bootcamp (BHP · UNAB · SENCE).

1.84 L

30·60·90

How I solved it

  1. Integration: JOIN of the fuel sensors with the equipment metadata.
  2. Temporal feature engineering: nivel_lag_1 (previous reading) and dt_min (minutes between readings).
  3. Honest validation: 80/20 temporal split without shuffling, so future data never leaks into training.
  4. Models: Linear regression as the baseline, compared with Lasso and Random Forest.
  5. Decision: 30/60/90-minute simulation and a criticality traffic light to rank refueling order.

Simplified outline of the approach

# Temporal features per vehicle
df = df.sort_values(["equipo_id", "timestamp"])
df["nivel_lag_1"] = df.groupby("equipo_id")["nivel"].shift(1)
df["dt_min"] = df.groupby("equipo_id")["timestamp"] \
    .diff().dt.total_seconds() / 60

# Temporal split (no shuffle)
cut = int(len(df) * 0.8)
train, test = df.iloc[:cut], df.iloc[cut:]

model = LinearRegression().fit(train[FEATS], train["nivel"])
pred = model.predict(test[FEATS])
print(mean_absolute_error(test["nivel"], pred))

# Traffic light: remaining autonomy in minutes
def traffic_light(minutes_left):
    if minutes_left < 30: return "RED"
    if minutes_left < 90: return "YELLOW"
    return "GREEN"
