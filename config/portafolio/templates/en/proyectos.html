1) EntreMuchos — Full-Stack Cloud Platform (www.entremuchos.cl)

A production web platform for a club and event venue in Santiago, Chile, bringing together in a single system: an online store for made-to-order clothing, digital ticket sales, bar tabs tied to each ticket, staff and finance management, a community (chat and bulletin board) and an AI assistant available on the web and on WhatsApp. It is a real product, with real users and real payments, built end to end: data modeling, backend, frontend, integrations, deployment and operations.

What it solves

  • EMStore: made-to-order clothing store with Pantone color variants, a shopping cart and in-person pickup at events.
  • Ticketing: digital tickets, FreePass, a 10-hour active-event window, an attendance panel and parking reservations.
  • Bar tabs: an open tab per ticket, itemized orders, automatic closing rules based on ticket type and coat-check control.
  • Internal management: weekly payroll calculated from shifts, rates and commissions; advances and bonuses; bar inventory; income, expenses, installment debts and a statistics dashboard.
  • Community: public channels and direct messages, a bulletin board with paid posts, a video gallery and a moderation queue.
  • Muchi (AI chatbot): a DeepSeek-based assistant that answers questions about tickets, the store and the venue location, both on the web and on WhatsApp.

Cloud architecture

  • Application: Django 6 + Python 3.13 served with Gunicorn on Railway, with continuous deployment from GitHub (every push to main triggers a deploy), reproducible builds (Nixpacks), persistent volumes and 100% environment-variable configuration (12-factor).
  • Data: MySQL 8 (utf8mb4) with 66 versioned migrations.
  • Files and video: Cloudflare R2 (S3-compatible storage via django-storages and boto3) and Cloudflare Stream (HLS video).
  • Static files: WhiteNoise with compression and a versioned manifest.
  • Observability: Sentry integration for error monitoring and tracing.
  • Payments: Flow.cl and Mercado Pago, covering one-time payments and recurring subscriptions (Preapproval), with an in-house payment audit tool.
  • Messaging: Resend (primary email) with the Gmail API as a fallback, and WhatsApp via Green API.

Security and privacy

  • Transport: mandatory HTTPS with SSL redirect, secure session and CSRF cookies, and HSTS for 1 year including subdomains and preload.
  • Credentials: passwords hashed with PBKDF2 and complexity validators; CSRF protection on every form; SECRET_KEY and all API keys kept out of the code (environment variables), with startup blocked if the secret key is missing.
  • Access control: attempt limit on the staff login (5 attempts, then a 15-minute lockout).
  • Age verification (21+) using the national ID number (RUT) and date of birth.
  • Privacy by design: the venue address is hidden on web tickets (it is only sent by email), plus report moderation.
  • Compliance: privacy policy aligned with Chile's Law 21,719 on personal data protection.

Technologies used: Python, Django, MySQL, Bootstrap 5, JavaScript, Chart.js, Gunicorn, Railway, Cloudflare (R2 and Stream), Flow.cl, Mercado Pago, DeepSeek API, Green API (WhatsApp), Resend, Gmail API, Sentry and WhiteNoise.

Full control panel (custom back office)

Besides the public side, I built an internal panel that lets the team run the whole business from one place, with staff-only access and functions separated by area. It replaces spreadsheets and manual processes with a single system connected to the same database as the store and the tickets.

  • Inventory: store products, categories and suppliers, plus bar inventory.
  • Events: event creation and management, active-event window, a real-time attendance panel and parking reservations.
  • Bar tabs: a tab opened per ticket, itemized order logging, automatic closing based on ticket type and coat-check control.
  • Point of sale: a "New Sale" module to record in-person sales at the venue, with a receipt and the associated seller.
  • Sales: management of customers, staff and sales, with a consolidated view per event.
  • Staff and payroll: weekly pay calculated from shifts, rates and commissions, with advances and bonuses.
  • Finance: income, expenses and debts with installment tracking.
  • Community and moderation: video gallery administration, a bulletin board with paid posts and a report queue.
  • Statistics dashboard: key indicators and Chart.js charts on revenue, new and repeat customers, tickets, FreePass issued, visits, external clicks and chatbot usage.
  • Users, profiles and roles: customer, staff and administrator profiles, with roles configurable straight from the panel, no code required. Each role defines what a person can see and do, and can have a salary assigned. Privileges follow the principle of least privilege: staff sign in with a 4-digit code and only see the information the administrator authorizes (role-based access control).
  • Panel security: access limited to authenticated staff, with a login attempt limit (5 attempts, then a 15-minute lockout).

2) Fuel Consumption Prediction for CAEX Haul Trucks (Mining)

A Machine Learning project that predicts the fuel level of CAEX haul trucks in order to anticipate refueling, reduce unplanned stoppages and support operational logistics in mining.

What it includes

  • Sensor data integration.
  • Exploratory analysis.
  • Temporal feature engineering.
  • Predictive modeling.
  • An operational prioritization layer using a traffic-light scheme.

Key technical contribution

  • Temporal model with variables such as nivel_lag_1 and dt_min.
  • High accuracy in short-term prediction (low MAE/RMSE and R² close to 1 in a simulated scenario).
  • Simulation of 30-, 60- and 90-minute horizons.
  • Logistics decision rules to determine which trucks should refuel first based on criticality.

Technologies and techniques

  • Tools: Python, Pandas, Scikit-learn, Matplotlib and Seaborn.
  • Temporal feature engineering and predictive modeling with regression.
  • Performance metric evaluation and visualizations to interpret the results.
  • Operational prioritization logic based on logistics rules.

The project demonstrates how data science can optimize critical processes in the mining industry.

3) REXFIRE Fire Extinguishers Website

A complete e-commerce platform for a Chilean fire extinguisher company, combining a public store with an administrative panel and an AI-powered sales assistant.

Store

  • Customers identify themselves by national ID number (RUT), with no password.
  • They browse the catalog with technical specifications, add products to the cart and complete the purchase.
  • PDF receipt generated automatically.
  • Applies 19% VAT, calculates shipping and offers free shipping above CLP $300,000.

  • Real-time access to inventory and prices.
  • Add to cart directly from the chat, and quotes sent by email.

Administrative panel

  • Full management of inventory, customers, suppliers, salespeople and sales.
  • Automatic 20% commissions for human salespeople.
  • Sales reports, chatbot conversation monitoring and order source (direct web vs. AI).

Technologies used

  • DeepSeek API (generative AI) and Twilio (WhatsApp).
  • Pillow and PDF generation.
